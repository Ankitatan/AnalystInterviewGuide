# SQL Interview Practice for Data Analysts

A hands-on SQL practice platform featuring interview questions, solutions, datasets, database management, query management, and real-world business case studies for aspiring Data Analysts.

## 🎯 What You'll Learn

- SQL fundamentals and filtering
- Joins and aggregations
- Subqueries and Common Table Expressions (CTEs)
- Window functions and ranking
- Business analytics and KPI calculations
- Real-world SQL interview problem solving
- Working with relational databases and structured datasets
- Writing, executing, saving, and managing SQL queries

## 📚 Difficulty Levels

- 🟢 Beginner
- 🟡 Intermediate
- 🔴 Advanced

## 🗄️ Database Management System

Manage datasets and practice SQL against structured data.

- **Upload datasets:** Import CSV files to create database tables.
- **Manage datasets:** View uploaded datasets and inspect table structures.
- **Explore schemas:** Review columns, data types, and table relationships where available.
- **Query your data:** Execute SQL queries against available tables.
- **Work with multiple datasets:** Use uploaded datasets for practical, real-world analysis.
- **Practice database concepts:** Explore filtering, joins, aggregations, and analytical queries.

## 📝 User Query Management System

Write, save, organize, and reuse your own SQL queries.

- **Create and save queries:** Store custom SQL queries for future reference.
- **Organize queries:** Give queries meaningful names and categorize them by topic or difficulty.
- **Edit and delete queries:** Maintain your personal query collection.
- **Search saved queries:** Quickly find queries by name, topic, or SQL content.
- **Execute queries:** Run saved queries against the selected dataset.
- **Review query history:** Revisit previously executed queries where history tracking is available.

## 🧠 Custom Interview Question Management

Build your own SQL interview practice library.

- Add custom questions with titles, descriptions, and difficulty levels.
- Categorize questions by SQL topic or business use case.
- Add hints, reference solutions, and explanations.
- Edit or delete questions as your practice needs evolve.
- Practice solving your own questions before reviewing reference solutions.

## 🛠️ How to Use This Repository

1. Choose a difficulty level or select a custom interview question.
2. Read the question and understand the business problem.
3. Upload or select a dataset containing the required tables.
4. Write your own SQL query before viewing the solution.
5. Execute the query and inspect the results.
6. Compare your output with the expected result or reference solution.
7. Save useful queries for future practice.
